## 2. In-Depth Evaluation Across Core Technical Domains

### A. AI Interaction Telemetry & Supported Integrations

- **Website Claim:** Captures keystroke timing, retry rates, revision and edit events around human-AI workflows.
- **Repository Reality:** The core platform in `C:\Projects\Promptsense` implements a Chrome Extension (Manifest V3) that binds to target web applications (specifically OpenAI ChatGPT, Anthropic Claude, and custom browser IDEs). It tracks input timing deltas, copy/paste events, prompt submissions, and response wait times.
- **Audit Verdict:** The technology is real, but the website fails to mention that the current ingestion mechanism is a **Chrome browser extension**. Buyers reading the website are left guessing whether they need an API proxy, an enterprise desktop agent, or a browser plugin.

### B. Behavioral Intelligence & 14 Capability Indicators

- **Website Claim:** A 14-dimension scoring engine that measures how humans grow with AI.
- **Repository Reality:** The metric catalogue (`PRAXYS_METRIC_CATALOGUE.md`) contains rigorous mathematical definitions for 14 primary dimensions and 7 secondary metrics:
  1. `skill_integrity`: Proportion of human reasoning preserved vs AI-generated text.
  2. `dependency_index`: Frequency of blind code acceptance and retry rate.
  3. `attention_score`: Dwell time and review duration before accepting outputs.
  4. `cognitive_offloading`: Ratio of outsourced analytical steps.
  5. `cognitive_practice_risk`: Frequency of bypassed foundational learning exercises.
  6. `retention_support_index`: Evidence of concept retention across sessions.
  7. `communication_clarity_score`: Precision of user prompts and instructions.
  8. `behavioral_stability_index`: Consistency of cognitive cadence over time.
  9. `prompt_effectiveness_score`: Iteration efficiency in reaching desired output.
  10. `learning_engagement`: Depth of exploratory probing and concept queries.
  11. `skill_execution_confidence`: Latency and friction during manual code editing.
  12. `knowledge_development_index`: Longitudinal trajectory of problem difficulty handled.
  13. `knowledge_transfer_readiness_index`: Ability to adapt learned concepts to new problem spaces.
  14. `interaction_strain_index`: Cognitive overload and frustration signals.
- **Audit Verdict:** The engine is deeply developed in the repository, making it one of the company's strongest IP assets. Hiding these 14 dimensions on the website is a massive missed opportunity.

### C. Enterprise Readiness, Scale & Customer Deployments

- **Website Claim:** "Partner with AutoPraxys on a capability intelligence pilot for your institution or organization."
- **Repository Reality:** `C:\Projects\Promptsense` has dedicated workspaces for `frontend-client001` (a tenant portal for pilot enterprise clients) and `PRE_CLIENT_PRODUCTION_READINESS_AUDIT.md`. Synthetic load audits (`PRAXYS_TONIGHT_200_USER_FINAL_READINESS.md`) have benchmarked the system up to 200 concurrent users.
- **Audit Verdict:** Enterprise readiness is in early pilot stage (10–200 users per cohort). The website accurately positions its offering as an **early-access institutional pilot partnership**, which matches the stage of the software.
